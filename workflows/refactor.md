# Refactor Workflow

## Scope
Code restructuring and improvement.

## Steps

### 1. Analyze (ECC + Graphify)
- Understand current structure
- Map dependencies via Graphify
- Identify refactoring scope

### 2. Plan (ECC)
- Design refactored structure
- Plan incremental steps
- Identify risk areas

### 3. Implement (ECC)
- Follow ECC methodology
- Make surgical, incremental changes
- Maintain test coverage

### 4. Verify (ECC)
- Run all tests
- Verify no regressions
- Verification loop

### 5. Simplicity Check (Ponytail — optional)
- Only if explicitly requested or warranted
- Check for unnecessary abstractions
- YAGNI analysis

## Capabilities Activated
- **Always**: ECC + Graphify
- **Simplicity review**: + Ponytail (explicit only)
