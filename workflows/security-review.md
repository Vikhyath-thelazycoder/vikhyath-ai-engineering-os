# Security Review Workflow

## Scope
Security-focused code review and hardening.

## Steps

### 1. Scope (ECC)
- Identify security-relevant code paths
- Classify sensitivity level

### 2. Static Analysis (ECC + Addy)
- ECC security scanning
- Addy OWASP Top 10 checks
- Dependency vulnerability scan

### 3. Code Review (Addy)
- Security hardening practices
- Secure coding patterns
- Input validation review

### 4. Specialist Review (Agency — optional)
- Security specialist for domain-specific concerns
- Only when expert review adds clear value

### 5. Verify (ECC)
- Verification loop
- Confirm all security checks pass

## Capabilities Activated
- **Always**: ECC + Addy
- **Domain expertise**: + Agency security specialist
